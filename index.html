Avoiding a missed code

The field is marked optional, and optional fields are the ones people skip. Enter the code before submitting, because referrals are tied to account creation. Spell it with the letter O, not a zero, and leave out any spaces. If you already have an account on the network, opening a second one to use a code is against poker room rules, so do not do it.
